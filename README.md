# Subtits — автоматические субтитры для видео (macOS)

Перетаскиваете видео любого формата → Whisper распознаёт речь (локально, без интернета) →
субтитры оформляются по пресету (шрифт, размер, цвет, положение, 1–3 строки, регистр и
пунктуация) → сохраняете видео со вшитыми субтитрами, прозрачный слой для монтажки или SRT.

Готовый установщик (DMG) лежит в [Releases](https://github.com/tihomirov-nick/subtits/releases/latest)
(инструкция для пользователей — `docs/Как установить.txt`). Локальная сборка кладёт его в `dist/Subtits-<версия>.dmg`.

## Возможности

- **Любые форматы видео** — декодирование через встроенный ffmpeg (MP4, MOV, MKV, AVI, WEBM, MTS, …),
  учитывается поворот видео с телефона, HDR (iPhone HLG) переводится в SDR.
- **Распознавание Whisper** (whisper.cpp, Metal на Apple Silicon). Модели скачиваются из приложения:
  Large v3 Turbo (рекомендуется), русские дообученные Large v3 Russian и Large v3 Russian Podlodka,
  Large v3, Medium, Small, Base, а также любая своя модель ggml `.bin`.
  Пословные тайминги — по выравниванию внимания (DTW), фильтр типичных «галлюцинаций» Whisper.
- **Пресеты**: шрифт и начертание, размер, цвет, межбуквенный и межстрочный интервал, обводка, тень,
  подложка (под каждой строкой или общая), положение (мышью на превью или слайдерами), ширина блока,
  1 / 2 / 3 строки, ограничение слов на экране и длительности субтитра.
- **Регистр и пунктуация — 4 варианта**: «Аа» со знаками, «Аа» без знаков, «аа» со знаками, «аа» без знаков.
- **Просмотр**: встроенный плеер с субтитрами поверх видео, покадровый шаг (← →), шаг по секунде (⇧← ⇧→),
  переход между субтитрами (↑ ↓), пробел или клик по видео — пауза. Шкала показывает, где есть субтитры,
  и время под курсором. Видео, которые macOS не воспроизводит сама (MKV, WebM, AVI…), в фоне перепаковываются
  или перекодируются в копию для просмотра (`Cache/Proxies`).
- **Всё в пикселях кадра**: X/Y, точка привязки (верх/центр/низ), ширина блока, размер шрифта, обводка, тень,
  отступы, межбуквенный и межстрочный интервал. Внутри пресет хранит значения независимо от разрешения,
  поэтому один пресет подходит к видео любого размера.
- **Редактор субтитров**: стиль задаётся каскадом **пресет → группа → субтитр → слово**. Вверху инспектора
  выбирается область («Все», «Группа», «Субтитр», «Слова»); изменённые свойства подсвечены, стрелка возвращает
  общее значение. Каждому субтитру — своё положение и оформление; группы (⌘G) — общий стиль для набора
  субтитров; слова выделяются щелчком на видео (⇧ — несколько) и получают свой шрифт, цвет, размер, наклон,
  ЗАГЛАВНЫЕ и выделение плашкой. Стиль слов сохраняется при правке текста, объединении и разделении.
  Копирование/вставка стиля (⌥⌘C / ⌥⌘V), правка текста и таймингов, разделение по курсору (⌘B), отмена (⌘Z).
  Расшифровки, группы и стили кэшируются — повторное открытие того же видео мгновенное.
- **Типографика**: начертание и шкала жирности по реальным начертаниям шрифта, курсив (настоящий или
  синтетический), наклон −30…30°, размер, межбуквенный и межстрочный интервал. Предупреждение, если в шрифте
  нет кириллицы.
- **Шрифты**: 8 популярных шрифтов встроены (Montserrat, Manrope, Oswald, Unbounded, Dela Gothic One,
  Playfair Display, Cormorant Garamond, Caveat), «Библиотека шрифтов» (⇧⌘T) ставит ещё ~45 бесплатных
  с кириллицей в один клик (Google Fonts, SIL OFL), платные Stapel и Akkordeon — ссылка на студию и импорт
  купленных файлов перетаскиванием. Шрифты macOS тоже доступны.
- **Экспорт**: MP4 H.264 / HEVC (аппаратное кодирование VideoToolbox), MOV ProRes 422 HQ,
  прозрачный слой ProRes 4444, SRT.
- Превью и итоговое видео рисуются одним и тем же кодом (CoreText) — что видно на превью, то и будет в файле.
- **Оформление в стиле iOS 27 и macOS 27 (Liquid Glass)**: плеер, подсказки и плашки статуса парят над видео
  в «жидком стекле», инспектор собран из карточек, как «Настройки» iOS, кнопки, поля и переключатели имеют форму
  капсул, содержимое инспектора и окон прокручивается под шапкой с мягким размытием края. На macOS 26 и новее
  стекло рисует сама система, на macOS 27 оно сразу выглядит так, как задумано в этой версии системы. На macOS 13–15
  вместо стекла используются полупрозрачные материалы. Учитываются «Уменьшить движение», «Уменьшить прозрачность»
  и «Увеличить контраст».
- Движение по принципам Apple (Designing Fluid Interfaces): раскладка «навигатор, просмотр, инспектор», пружинные
  анимации без перелёта, перетаскивание 1:1 с мягкими границами и прилипанием к центру (с тактильным откликом).

## Системные шрифты или свои

Приложение показывает и шрифты macOS, но для команды надёжнее встроенные и библиотечные: набор шрифтов
macOS отличается на разных Mac и версиях системы, шрифты из «Шрифтов» (Font Book) есть только на том Mac,
где их установили, а многие системные шрифты без кириллицы. Если пресет ссылается на шрифт, которого на
другом Mac нет, субтитры там нарисуются запасным шрифтом. Встроенные шрифты одинаковы везде, библиотечные
ставятся одной кнопкой.

## Шрифт Stapel (ParaType)

Stapel — коммерческий шрифт (ParaType), в репозитории его нет. Пресеты по умолчанию настроены на Stapel;
пока шрифта нет, временно используется Montserrat — в интерфейсе показывается предупреждение.
Akkordeon (Emtype Foundry) тоже платный и **без кириллицы**: русские буквы им не нарисовать.

Два способа подключить Stapel:

1. **Вшить в приложение (для всей команды)** — положите лицензированные файлы `.otf`/`.ttf`
   в папку `Fonts/` и пересоберите DMG (`./scripts/make_dmg.sh`). Шрифт будет доступен на всех Mac,
   где установлено приложение. Проверьте, что лицензия ParaType покрывает нужное число компьютеров.
2. **На одном Mac** — кнопка «Файлы…» в разделе «Шрифт» или пункт «Добавить файлы шрифтов…» в меню «Стиль» (файл копируется в
   `~/Library/Application Support/Subtits/Fonts`).

## Язык интерфейса

Subtits работает на русском и английском, язык выбирается в настройках (⌘,). По умолчанию включён
режим «Автоматически»: русский, если он есть среди языков macOS, иначе английский. Меню и системные
окна переключаются вместе с приложением после перезапуска.

Строки в коде написаны по-русски внутри `L("…")` и служат ключами перевода. Английский перевод лежит
в `scripts/l10n/en.json`. Из него `scripts/l10n/make_strings.py` собирает
`Resources/en.lproj/Localizable.strings` и останавливает сборку, если у какой-то строки нет перевода
или не совпадают `%@`.

## Сборка

Нужны Xcode (Swift 5.10+) и Homebrew `cmake` (только для сборки whisper.cpp).

```bash
./scripts/make_dmg.sh            # всё сразу: зависимости → Subtits.app → dist/Subtits-1.0.0.dmg
VERSION=1.1.0 ./scripts/make_dmg.sh
```

Отдельные шаги:

| Скрипт | Что делает |
|---|---|
| `scripts/build_whisper.sh` | собирает whisper.cpp 1.9.4 (Metal + Accelerate) как universal static library → `Vendor/whisper` |
| `scripts/fetch_ffmpeg.sh` | скачивает статический ffmpeg 9.0.2 (arm64 + x86_64, ffmpeg.martin-riedl.de), проверяет SHA-256, склеивает в universal → `Vendor/ffmpeg` |
| `swift scripts/make_icon.swift` | рисует иконку → `Resources/AppIcon.icns` |
| `scripts/build_app.sh` | universal-сборка приложения → `build/Subtits.app` (ffmpeg в `Contents/Helpers`, шрифты из `Fonts/`), версия SDK в бинарнике, подпись |
| `scripts/make_dmg.sh` | `build_app.sh` + DMG с ярлыком Applications и инструкциями на русском и английском |
| `scripts/release.sh` | публикует релиз на GitHub: собирает DMG из закоммиченного кода, ставит тег `v<версия>`, пушит и создаёт релиз с DMG (`VERSION=1.5.0 NOTES=заметки.md ./scripts/release.sh`, нужен токен GitHub в Связке ключей) |

SwiftPM записывает в поле SDK бинарника минимальную версию системы (13.3), а macOS по этому полю решает,
показывать ли приложению современный дизайн. Поэтому `build_app.sh` после компиляции записывает туда настоящую
версию SDK (`vtool -set-build-version`). Без этого шага на macOS 26 и 27 приложение выглядит по-старому, без Liquid Glass.

Разработка: `swift build` и консольная утилита для проверки конвейера без интерфейса:

```bash
swift build --product subtits-cli
.build/debug/subtits-cli transcribe video.mp4 --model ~/Library/Application\ Support/Subtits/Models/ggml-large-v3-turbo-q8_0.bin --out t.json
.build/debug/subtits-cli cues t.json --preset 0
.build/debug/subtits-cli export video.mp4 t.json --out result.mp4 --format mp4H264
```

## Подпись и Gatekeeper

По умолчанию приложение подписывается ad-hoc, поэтому на других Mac при первом запуске нужно
разрешить его в «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть»
(подробно — в `docs/Как установить.txt`). Чтобы предупреждения не было, нужен сертификат
**Developer ID Application** (Apple Developer Program) и нотаризация:

```bash
SIGN_IDENTITY="Developer ID Application: Имя (TEAMID)" ./scripts/make_dmg.sh
xcrun notarytool submit dist/Subtits-1.0.0.dmg --keychain-profile <профиль> --wait
xcrun stapler staple dist/Subtits-1.0.0.dmg
```

## Где что лежит

- `Sources/SubtitsCore` — распознавание (`WhisperEngine`), нарезка на субтитры (`CueBuilder`, `LineBreaker`),
  отрисовка (`SubtitleRenderer`), ffmpeg (`FFmpeg`, `Exporter`), каталог моделей.
- `Sources/Subtits` — интерфейс SwiftUI; `Player/` — плеер на AVFoundation (покадровый шаг, точная перемотка).
- Данные пользователя: `~/Library/Application Support/Subtits/` — `Models/` (модели), `Fonts/` (добавленные шрифты),
  `presets.json` (пресеты), `Cache/` (расшифровки).
